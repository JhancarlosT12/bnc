CIBStyle Sans — versión para proyecto académico

Esta familia NO es CIB Font Sans de Bancolombia ni pretende ser una copia de su fuente propietaria.
Es una alternativa original basada en Lato (licencia SIL Open Font License), ajustada y renombrada
para facilitar su uso dentro del proyecto.

Archivos:
- CIBStyleSans-Regular.ttf
- CIBStyleSans-Medium.ttf
- CIBStyleSans-Bold.ttf
- CIBStyleSans.css

Para web, carga el CSS y usa:
font-family: 'CIBStyle Sans', sans-serif;
